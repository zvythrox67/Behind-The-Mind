# Behind the mind

A psychological exploration game about an alien trapped inside a human mind.

## About

You play as EOS, an alien explorer who enters a human mind to study how the human brain works. A neural feedback loop traps EOS inside, and the only way out is through the mind's most hostile regions. Each region manifests a different mental health struggle. You cannot fight the mind, only navigate and understand it.

## Gameplay

- Explore five mindscapes: depression, anxiety, panic, trauma, burnout
- Survive using adaptation and puzzle-solving, not combat
- Collect memory fragments for lore, shortcuts, and alternate endings
- Multiple endings based on understanding vs. escape speed
